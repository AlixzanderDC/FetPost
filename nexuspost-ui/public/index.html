FetPost setup
A few quick questions and you're ready to post.

Step 1 — Set an admin password

This is how you'll log into FetPost. Pick something strong; you'll only need it on this device.

Step 2 — Enter your license key

Alixzander emailed you a license key after your Ko-fi payment. Paste it here. The key activates posting and unlocks the auto-update feed.

Lost your key? Email Alixzander with your Ko-fi receipt.

Step 3 — Connect your first FetLife account

Tell FetPost which FetLife account to post for. You can add more accounts later from Settings.

A short nickname FetPost uses internally. Letters, numbers, dashes only.
FetPost stores this only long enough to capture a session cookie on the next step. It never leaves your server.

Step 4 — Log into FetLife

FetPost posts as your account by reusing a logged-in browser session. Clicking below opens a remote browser running on your server — log into FetLife inside it, and FetPost will save the session. You only do this once per account.

What to expect: a new browser tab opens, shows a Chrome window from your droplet, and lands on the FetLife login page. After you log in and reach FetLife's home page, click "I've logged in" in that tab. Then come back here.

You're all set. 🎉

FetPost is ready. Log in with the admin password you just set to start scheduling posts.

Templates

Placeholder reference

{Event Name}Title of the pinned event

{Insert Next Event Date}Date of next upcoming hosted event for the account
{Insert Next Event Link}URL of next upcoming hosted event for the account
Matching is lenient — case-insensitive, accepts natural variants like {insert event link here} or {next event date}.

Campaigns

Reusable campaign templates for the selected festival/conference account. A campaign defines a posting cadence (relative to your event start date) and a content roster (educators, special events, info topics). Activating it generates concrete scheduled posts — preview before committing.

The Campaigns tab only shows for accounts of type Festival / Conference / Hotel Takeover. Set an account's type from the Accounts tab to see its campaigns here.

Active runs

Each row is an activation that generated scheduled posts. Use "Unschedule" to cancel all posts from a single activation in one click.

Events

The main festival plus any lead-up sub-events (meet & greet, interest workshop, hotel info night…). Each post in this campaign anchors to one of these events for its schedule and for the {Event Link} / {Event Date} / {Event Name} placeholders. Mark one event as Primary — that's the default anchor.

Posts in this campaign

Each row is one scheduled post. Write the actual content you want to publish — every post should be different. Schedule is days/hours relative to the picked anchor event. Placeholders resolved at activation: {Event Name} {Event Date} {Event Link} {Days Until}.

Generate cadence

Adds N slots to this campaign on a fixed cadence (every week, every other week, monthly, etc). Each generated slot is a normal post — you can edit it after the fact in the slot list.
